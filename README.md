# SpendWise - Budget Tracker

### Project Description
SpendWise is a simple web-based budget application designed to help users input their total monthly budget and tracked expenses, automatically calculating their remaining balance.

### JavaScript Concepts Implemented
* **Variables**: Used `let` to hold changing numerical data like inputs and final balances.
* **User Input**: Collected dynamic data using the built-in browser `prompt()` method.
* **Data Type Conversion**: Converted string text from prompts into printable figures using `Number()`.
* **Functions**: Designed a reusable `calculateBalance` function to separate arithmetic execution from main display workflows.
* **Arithmetic Operations**: Handled balance reduction calculations via subtraction (`-`).
* **Console Outputs**: Logged descriptive text block labels out into the browser using `console.log()`.
